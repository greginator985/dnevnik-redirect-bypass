# dnevnik-redirect-bypass
Убирает окно с просьбой подтвердить переход по ссылке на  dnevnik.ru


## Инструкция:
1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) для вашего браузера.
2. [Нажмите сюда для установки скрипта](https://raw.githubusercontent.com/greginator985/dnevnik-redirect-bypass/main/script.user.js).
3. [Продвнутый скрипт (Подтвеждение прямо на странице)](https://raw.githubusercontent.com/greginator985/dnevnik-redirect-bypass/main/script2.user.js).
4. Подтвердите установку во всплывающем окне.

Теперь при переходе по внешним ссылкам в Дневнике вы будете сразу попадать на нужный сайт.
